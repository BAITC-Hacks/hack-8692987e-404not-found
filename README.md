# Beeline tariff campaign agent

Локальная версия агента для задачи выбора тарифных кампаний. Агент строит
кандидатов, запускает пилоты и формирует не более десяти кампаний в
`submission.csv`.

## Быстрый запуск

В PowerShell из папки проекта:

```powershell
py -3 make_submission.py
```

В текущем репозитории команда использует `local_eval.py` — небольшое
детерминированное окружение без pandas и других внешних зависимостей. В выводе
появятся количество кампаний, локальный score и проверка ограничений.

Результат находится в `submission.csv`.

В веб-интерфейсе можно выбрать CSV-профиль клиентов. Обязательные колонки:
`current_tariff`, `arpu_segment`, `data_segment`, `predicted_arpu`. После загрузки
нажмите «Запустить агента» — кампании будут рассчитаны по загруженным строкам.

## Важное ограничение

`local_eval.py` — только локальный smoke-test. Официальный judge и его датасет
в репозитории отсутствуют. Когда организаторы предоставят официальные файлы,
их нужно положить в корень проекта; `make_submission.py` автоматически пытается
использовать `make_env()` из `local_eval`, `eval`, `runner` или `main`.

## Основные файлы

- `agent.py` — стратегия выбора кампаний и пилотов.
- `make_submission.py` — запуск агента и генерация CSV.
- `local_eval.py` — локальная среда и базовая проверка результата.
- `submission.csv` — последний сгенерированный результат.
